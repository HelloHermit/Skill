# 模拟提问清单

生成 15–20 条，覆盖五类。每条答案写成三句式，控制在 3 句内，**念一遍确认不超过 20 秒**。

## 填写模板

| # | 问题 | 类别 | 三句式答案（承认→定级→改进） | 风险 |
|---|---|---|---|---|
| 1 | 为什么用 A 不用 B？ | 方法 | ①我们选 A 是因为… ②B 在本场景的问题是… ③如果时间允许会补 B 的对照实验 | 中 |
| 2 | 这个数字的样本多大？ | 数据 | | 高 |
| 3 | 你们方案最大的问题是什么？ | 缺陷 | | 高 |
| 4 | 这个创新点和已有工作差在哪？ | 概念 | | 高 |

风险列标"高"的，就是必须提前写死的答案；标"高"但写不出来的，准备诚实话术。

## 五类问题生成提示

**概念类**（3–4 条）
- 你的核心术语和它最像的那个概念，区别是什么？
- 这个指标的定义是什么？为什么用它衡量？
- 你提到的 X 属于哪一类方法？

**方法类**（4–5 条）
- 为什么用这个算法/材料/架构，不用更常见的那个？
- 参数怎么定的？调过吗？
- 有没有做消融/对照？去掉某个模块会怎样？

**数据类**（3–4 条）
- 数据从哪来？多大？清洗规则？
- 这个提升是相对什么基线？
- 误差来源主要是什么？
- 重复实验了几次？

**缺陷类**（3–4 条）
- 最大的短板是什么？
- 换到真实场景会失效吗？在什么条件下失效？
- 成本/功耗/时延能接受吗？

**动机类**（2–3 条）
- 为什么做这个题目？
- 谁会用？替代方案是什么？
- 下一步做什么？

## 诚实话术（背下来，别现场编）

- "这部分我们确实没做，目前只验证了 X。"
- "这个数我需要回去核对，现在不敢给您一个准数。"
- "这是我们设计的取舍：牺牲了 A 换 B，因为场景里 B 更关键。"
- "您说的这个角度我们没考虑到，回去会补一组实验。"
