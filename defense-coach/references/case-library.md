# 案例库：三个可对照的结构

来源：依力（2026-07-25 课程）自述的三个项目 deck。数字与结论为讲师自述，未经独立核实；这里只提取**结构**，不背书战绩。

## 案例 A：工科特等奖（智能导航小车，SRTP）

**背景**：本科科研训练项目，讲师称获校级特等奖。同期有同学做八足/蜘蛛机器人，技术复杂度更高。

**讲述结构（约 6 段）**：

1. 一句话定位："基于机器视觉和测距技术的智能导航小车，目的是模拟真实无人驾驶的决策过程"
2. 硬件层：阿克曼底盘 + 开发板 + 激光雷达 + 摄像头
3. 底层控制：STM32 + IMU + 电机驱动
4. 上层：Jetson Nano 对接传感器；PC 端 Ubuntu + ROS 远程操控
5. 算法链：EKF 融合里程计与陀螺仪做位姿估计 → 激光 SLAM 建图 → costmap 膨胀 → 全局路径规划（欧氏距离）+ 局部优化（TEB）→ AMCL 修正累积误差 → YOLOv3 视觉识别
6. 收尾：以上是完整框架，请各位老师批评指正（**末页为全篇大纲，不讲**）

**可迁移的点**：

- 术语密度高但每页字少——专业感来自"名词准确"，不是来自"文字多"
- 每一层都回答"这层解决什么问题"，而不是"我用了什么库"
- 技术复杂度不占优时，靠**逻辑完整性 + 表达**拉开差距（讲师自己的总结："凭什么拿特等奖？因为答辩"）

## 案例 B：创赛（OceanWings 海上垃圾回收，全国节能减排大赛决赛）

**开场 40 秒的数据压迫**：

> 全球每年塑料产量接近 8 亿吨 → 9% 被回收 → 大量随意丢弃 → 每年 400–1200 万吨入海 → 2050 年海洋塑料总数量将超过鱼类

**问题定义（逐条否掉现有方案）**：

- 传统：拦截浮体（被动）、专业清理船（能耗高成本高）、人工小船（耗时耗力）
- 较新：海上垃圾桶、洋流回收器、太阳能水车、拦截系统
- **共性缺陷一句话收口**：全部依赖洋流被动收集，对远洋垃圾无效

**方案**：附着于商船/渔船的双臂协调回收系统，随船移动、主动收集、多船通用

**收尾结构**：技术路线图 → 详细设计（标注每个部件作用）→ 实验（难点 1/2/3 分页）→ 经济性分析 → 环保分析

**可迁移的点**：

- "逐条否定现有方案 + 一句话共性缺陷"是创赛最有效的立项叙述
- 难点分页（难点一/二/三）等于提前把评委的问题编号，答辩时可以直接说"这是我们的难点二"
- 公认背景（塑料污染严重）只用一页，不铺陈——评委已经知道的事不值得占时间

## 案例 C：商赛（HealthMirror，毕马威商赛）

**形态**：PPT 即交付物，无人讲述，评委自行翻阅。

**结构**：Part 1 Overview → Part 2 Market Analysis → 产品 → 商业模式 → 团队

**特征**：

- 顶部保留章节条（对应学术答辩的左侧目录）
- 信息密度显著高于答辩型 deck，接近论文排版
- 单页承载"一屏可读完"的完整论证，而不是一句结论

**可迁移的点**：判断标准只有一个——**有没有人站在台上讲**。有，走答辩打法；没有，走论文打法。两套规则不能混用。
