# 学术答辩 PPT 规则

来源：依力《高效沟通、领导能力与学术答辩》（2026-07-25）讲授 + 其三个实战 deck 的结构拆解。标注"（补充）"的条目是本 skill 基于同一逻辑外推的实践建议，非课程原文。

## 一条判断依据

评委看到花里胡哨、光污染、元素堆满的 PPT，第一反应是"这人做的东西大概不怎么样"——因为**做得越差的人越需要华丽的东西修饰**。这不是审美偏好，是长期评审形成的捷径判断。你的任务是不触发它。

## 七条硬规则

| # | 规则 | 具体做法 |
|---|---|---|
| 1 | 关键不在 PPT 上写了什么 | 满页文字会让评委先念完再走神；每页只放"看"的东西（图、表、关键词） |
| 2 | 学术场景一律偏素 | 白底或浅底 + 单色强调；拒绝渐变、阴影、3D、艺术字 |
| 3 | 不能纯白底黑字（除非院士） | 保留 logo、页眉线、统一字号层级；"素"不等于"偷懒" |
| 4 | 布局要有逻辑感 | 讲底层框架，图就画在下方；讲上层应用，就放上方。方位跟叙述方位一致 |
| 5 | 每页 ≤50 字 | 学术答辩的硬上限；超了就拆页或删字 |
| 6 | 图表必须规范 | 图有 X/Y 轴含义、单位；表有字段表头；公式用 LaTeX；logo 位置全程不变 |
| 7 | 动画只用"出现/消失"或"渐变" | 旋转、飞入、音效一律不要；动画唯一功能是控制信息释放顺序 |

## 布局骨架

```
┌──────────────────────────────────────┐
│ [logo，全程同一位置]      页码/章节     │
├───────────┬──────────────────────────┤
│ 1 背景     │  本页标题（≤12 字）        │
│ 2 ■ 方法   │                          │
│ 3 实验     │  一张主图 / 一张表         │
│ 4 结论     │  + 一行结论句（≤20 字）    │
└───────────┴──────────────────────────┘
   常驻目录，随进度切换高亮（不要只在首页放目录）
```

左侧常驻目录是最高性价比的设计：评委随时知道"讲到全局的哪一步"，不会在中途失去定位。绝大多数人只在第一页放一次目录，讲完就翻过去，等于没放。

## 末页：不要写"谢谢老师"

常规做法是末页放"感谢聆听"，然后进入提问。问题在于：提问的十分钟里，评委眼睛盯着的是这四个大字，脑子里是发散的，于是问出你根本没准备的问题。

改成：**末页放全篇大纲**——把讲述的所有要点凝练成一页，转过去，只说一句"以上是我今天答辩的全部内容，恳请各位老师批评指正"，这一页不讲。

机制：评委提问时必须睁眼看着这页（PPT 就在台上，躲不开），问题会被锚定在你给出的框架里。前提是大纲页要**覆盖你希望被问的范围**，且层级清楚。

（补充）这条不是万能的：遇到特别懂行的评委，他仍会跳出去问底层原理。所以它降低方差，不消除风险——底层概念该准备的还是要准备。

## 图表规范清单

- 图：坐标轴名称 + 单位 + 图例；不要直接从论文截图（分辨率会糊），重画或导出矢量
- 表：三线表或清晰表头；数字对齐小数位；单位写在表头
- 公式：LaTeX 手打，不要截图；变量在首次出现处解释
- 流程图：箭头方向统一，颜色不超过 3 种
- 所有图的配色与全篇一致（一套色板用到底）

## 商赛 / 创赛变体

当 PPT 本身就是**要交的作业**（没有讲述时间，评委自己翻），规则 5（≤50 字）失效，改为：

- 追求"一页承载完整信息"，接近论文排版：分 Part（Overview / Market / Product / Model / Traction）
- 每页顶部保留章节条，让翻阅者知道结构
- 图表密度提高，但字号不得小于 10 pt（打印后仍可读）
- 仍然保留：配色克制、图表规范、logo 固定

判断标准很简单：**有没有人站在台上讲。** 有 → 学术答辩打法；没有 → 论文打法。

## 三个反面样本（评审现场高频）

1. "以梦为马，不负韶华"式模板：四张大图毫无信息量，文字堆在下面
2. 四个大箭头指着四个并列概念，但概念之间没有推导关系
3. 每页都有跳动的装饰元素，讲者一按键就有一段文字旋转着落下来
