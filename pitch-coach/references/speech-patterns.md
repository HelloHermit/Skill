# 句式库

标注（补充）的为本 skill 外推，其余来自依力（2026-07-25）课程。

## 把"我要"翻译成"你得到"的三步

```
1. 写出你的诉求：我想当班长。
2. 写出对方的处境：他刚来，谁都不认识，担心有事没人管。
3. 找交集：我当班长 = 你的事有人接。
```

练习方法：拿你准备说的每一句"我想/我会/我能"，逐句问"这句话对方能得到什么"，答不上来就删。

## 五种开场（选一，别叠加）

1. **直给身份 + 反差点**："我叫 X，学计算机的，但我今天想讲的不是代码。"
2. **具体场景**："昨晚十一点，宿舍群里有人问教务系统怎么登，没人回。"
3. **一个数字**："我们班 42 个人，31 个不知道奖学金什么时候评。"
4. **承认紧张（慎用）**："我上台前想了一晚上要不要来。"——只适合真诚路线，且必须立刻转向内容
5. **直接给承诺**："我先说结论：如果我当选，你们的事我会接。"

**禁用开场**：大家好我很荣幸站在这里 / 首先感谢主办方 / 我今天要讲三点。

## 三种收尾

1. **请求型（竞选）**："如果你也遇到过刚才说的那种情况，投我一票。"
2. **邀请型（面试/社团）**："我想来这里做这件事，具体怎么开始，我听安排。"
3. **留钩型（路演）**："这是我们做到的程度，接下来想验证的是 X，欢迎拍砖。"

**共同点**：最后一句是动作请求，不是"谢谢大家"。

## 事实化改写表

| 原句 | 改后 |
|---|---|
| 我很有责任心 | 高中三年我负责班级考勤，没漏过一次 |
| 我学习能力强 | 暑假两个月自学完 X，做出了 Y |
| 我参加过很多比赛 | 数模国赛省二，负责建模与论文写作 |
| 我沟通能力好 | 上次社团活动我协调了 3 个部门、12 个人 |
| 我很想加入 | 我看了你们去年的项目，卡在 X 上，我有个想法 |

## 删稿四刀（按顺序）

1. 砍形容词
2. 砍形容词化的经历
3. 把剩下的换成可验证事实
4. 砍掉所有客套开场

砍完还剩 30 秒以上的，说明还有水分。

## 语速与停顿

- 铺垫、衔接句：可以快，听众会自动降采样
- 关键句：放慢 30%，前面加 0.5 秒停顿
- 承诺句：说完停 1 秒，不要立刻接"谢谢"

这不是表演技巧，是**信息密度调度**——人的注意力有带宽上限，全程高密度等于全程没重点。
