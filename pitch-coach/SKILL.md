# Pitch Coach

## Overview

三分钟以内的发言，胜负不在文采，在**你有没有回答台下那个人心里那句话**——"这跟我有什么关系"。绝大多数人上台讲的是"我是谁、我多努力、我想要这个位置"，台下听到的是噪音。

这个 skill 只做一件事：把"我想要"翻译成"你能得到"，然后压缩进时限。

## 第一步：先把台下搞清楚（不问清就别写稿）

必须确认四件事：

1. **听众是谁**：同龄同学 / 学长学姐 / 老师 / 混合评委
2. **他们此刻在干什么**：刚军训完很累？刚听完 8 个人讲？只想赶紧结束？
3. **他们要做什么决定**：投票 / 打分 / 筛人 / 只是听
4. **这个决定对他有什么成本**：投你一票有没有风险？选你他会不会后悔？

第 4 条最容易被忽略：**投票是有成本的**。他怕选错人、怕被卷、怕承诺兑不了。你的稿子要降低这个成本，而不是加大承诺。

## 第二步：选结构

三种结构，按场景选一种，不要混：

**A. 竞选型（班委、社团负责人）**

```
身份一句话 → 我看见的一个具体问题 → 我打算怎么做（一件可验证的小事）
→ 一句话承诺（把你的需求和他们的需求接上）→ 请求投票
```

**B. 面试型（社团、学生会、二次选拔）**

```
我是谁（一句，带一个可验证的事实）→ 我做过什么（一件，有数字/结果）
→ 我能给你什么（对方视角的收益）→ 我想在这里做什么
```

**C. 路演型（项目/比赛 3 分钟）**

```
问题（一个数字）→ 现有方案的缺陷 → 我们的做法 → 证据 → 请求（资源/投票/反馈）
```

## 第三步：写和删

写第一稿不要管长度，写完按这个顺序删：

1. 删所有形容词（"非常有责任心""特别热爱"）
2. 删所有形容词化的经历（"我参加过很多活动"）
3. 把剩下的每句话换成"可验证的事实"（数字、结果、时间、角色）
4. 删掉所有开场客套（"大家好，很荣幸站在这里"）

**剩下的骨架应该在 30 秒内讲完。** 讲不完，说明你在讲自己，不是在讲对方。

## 第四步：排练（比写稿重要）

只看四个指标：

| 指标 | 合格线 |
|---|---|
| 时长 | 目标时长的 90%（留缓冲，别卡点） |
| 语速 | 关键句放慢，铺垫句可以快——用速度差制造重点 |
| 眼神 | 每 5–8 秒扫一次台下，不要盯屏幕 |
| 结尾 | 最后一句是请求，不是"谢谢大家" |

**不要背全文。** 背稿会在紧张时断片，而且听起来像念。只背三个点：开头第一句、承诺句、结尾请求句。

## 一句话法则（所有短发言的通用检验）

上台前问自己：

> 台下这个人，他希望站在这里的应该是个什么样的人？

班委竞选，他希望的是"我的事有人管"，不是"这人有三年班长经验"。
社团面试，他希望的是"这人来了能干活"，不是"这人很热情"。

**把答案变成你的第一句或最后一句。** 中间内容服务于它。

## 反例（现场高频，逐条对照）

| 说的话 | 问题 |
|---|---|
| "我高中三年都是班长，所以大学也想为大家负责" | 你的经历跟他们的收益无关 |
| "我是一个有责任心、乐于助人的人" | 形容词不算证据 |
| "希望大家给我一个机会" | 请求模糊，对方不知道投你意味着什么 |
| "如果我当选，我会带大家吃香喝辣" | 承诺不可验证，反而提高对方的怀疑成本 |
| "谢谢大家"（作为结尾） | 浪费了最后一次强化请求的机会 |

## 禁区

- 不写空承诺（"带大家搞钱""让班级成为最牛的班"）
- 不贬低对手，不暗示"别人不行"
- 不虚构经历、职务、获奖
- 不把"内向"当缺陷解释半天——直接给事实，性格不需要道歉
