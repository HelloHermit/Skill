# 一页纸谈判准备表

谈判前 10 分钟填完。填不满的格子，就是你会在现场被问住的地方。

## 1. 基本盘

| 项 | 填 |
|---|---|
| 我要的（具体、可量化） | |
| 我的底线（低于此就放弃） | |
| 我的退路（谈不成怎么办） | |
| 对方要的（只能选一个主诉求） | 钱 / 时间 / 面子 / 风险 / 人情 |
| 关系强度 | 弱 / 中 / 强 |
| 时间压力在谁那边 | 我 / 对方 / 都没有 |

**退路这一栏最关键。** 没有退路的人谈不成——因为你不敢走，对方能看出来。

## 2. 筹码清单（写不出三条就别谈）

| 筹码 | 类型 | 对方在不在乎 |
|---|---|---|
| | 现钱 / 未来回报 / 公开认可 / 稀缺信息 / 帮他省事 / 情绪价值 | 高 / 中 / 低 |

## 3. 换货币方案

如果核心障碍是价格/资源差距，列出三种非现金补偿：

1. 未来互惠：______（具体到"什么时候、做什么"，不要"以后有事你说话"）
2. 公开认可：______（署名、致谢、朋友圈、汇报里点名）
3. 降低对方成本：______（我自己先做完 60%，你只需要审）

## 4. 台阶设计

- 休会理由：______（"我们各自内部过一下"）
- 谁先开口：**我方**
- 我方的最后一步让步：______（提前想好，别现场挤）
- 对方点头时需要说的话：______（给他一个体面的成交句）

## 5. 三句预案

| 场景 | 我说什么 |
|---|---|
| 对方直接拒绝 | |
| 对方压价/加码 | |
| 对方问"你为什么不去找别人" | |

## 6. 事后

| 项 | 填 |
|---|---|
| 实际结果 | |
| 哪一步起了作用 | |
| 哪句话让对方停顿了 | |
| 下次改什么 | |

最后两栏比结果更重要——谈判是可以练的技能，但只有记录才能迭代。
