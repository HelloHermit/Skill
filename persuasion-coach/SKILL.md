# Persuasion Coach

## Overview

说服不是把对方压服，是**让对方在不损害自尊的前提下做出对你有利的选择**。绝大多数请求失败，不是因为你理由不够，是因为你让对方付出了他不想付的代价——钱、面子、时间，或者"我好像被占了便宜"的感觉。

谈判桌上的数字往往不是真障碍，**身份感**才是。5000 元的单子对方不缺，但"接 1500 的单"会掉价，所以真正要解决的从来不是价格。

## 开工前先算三个量

1. **关系强度**：弱关系（一次合作）/ 中关系（同学、社团）/ 强关系（室友、队友、导师）
2. **对方要什么**：钱、时间、面子、风险可控、人情、长期资源——**只能选一个主诉求**
3. **你的筹码**：现钱、未来回报、公开认可、稀缺信息、帮他解决麻烦、情绪价值

筹码清单写不出三条，说明这次谈判你处于纯劣势，先别谈，先造筹码（比如先做出一点东西给对方看）。

## 四步法（对方不缺钱、但怕掉价时用）

```
① 真诚亮底：把预算/能力上限说实话（可略低于真实值，留一点加价空间）
② 抬高对方：承认对方的价值远高于这个数（"这对你们不算什么，你们能拉到的高度我们达不到"）
③ 换货币支付：用尊重、未来互惠、第一次合作的叙事，把那部分差价补上
④ 给台阶：主动提出休会、主动加价，让对方不必背"砍价"的心理负担
```

关键在第 ④ 步：**不要让对方面对"降还是不降"的二选一**。你把话说到位，然后说"我们先各自讨论五分钟"，回来由**你先开口**加价——对方只需要点头。

完整复盘见 `references/negotiation-four-steps.md`。

## 拒绝：先判断，再选工具

| 情形 | 用哪种 |
|---|---|
| 平级、长期合作、对方能承受直话 | **直接拒绝**（"我这周排满了，做不了"） |
| 弱关系、一次性请求、不想消耗关系 | 第三方白脸（"我正在外地，回来再说"） |
| 对方是上级/长辈，直接说不方便 | 条件拒绝（"如果只做 A 部分，我可以"） |
| 一时判断不了、需要时间 | 延迟（"我今晚看一下安排，明早回你"） |

**默认推荐直接拒绝。** 第三方理由最大的风险是被抓包，一旦被抓，信用归零，而且你以后所有的话都要打折。详细边界与翻车案例见 `references/refusal.md`。

## 写请求消息的四段式（补充，非课程原文）

课程提到"给导师发邮件进组"是高频道场景，但没展开方法。这里给一个符合同一逻辑的结构：

```
① 我是谁 + 一句可验证的事实（专业/年级/做过什么）
② 我为什么找你（读过你哪篇/哪个项目，具体到点）
③ 我能提供什么（时间投入、已有技能、能接的具体活）
④ 明确的小请求（不是"收我为徒"，是"能否给我 15 分钟"或"能否让我先跟一次组会"）
```

要点：**请求要小到对方拒绝的成本很低**。第一次就要求"进组"，对方要给的是一个位置；要求"听一次组会"，对方给的是一个座位。

## 五个常见错误

1. **把理由当筹码**：说了一堆"我很难/我很想"，对方没有义务为你的困难买单
2. **一次给太多选项**：让对方在三个方案里挑，等于把决策成本转嫁给他
3. **逼当场表态**："你现在能不能定"——逼出来的"行"通常是"不行"的礼貌版
4. **只谈自己**：全程"我需要"，没有一句"你能得到"
5. **承诺不可兑现**："以后有事你说话"这种空头支票，说多了会贬值；给具体的、你能做到的小承诺

## 禁区

- 不教操控、不教隐瞒关键信息、不教利用对方情绪弱点的技巧
- 不替用户决定让利底线——给区间和判断依据，底线由用户自己定
- 不承诺"这样谈一定成"。对方有独立的决策逻辑，本 skill 只提高命中率
